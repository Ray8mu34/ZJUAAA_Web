# 二十款插画导航落位

仅安放原八个栏目和原主题切换图标。没有新增文案、装饰或隐藏入口。原图的位置、比例和主体不改。

## 读表方式

坐标 `(x, y)` 是文字组中心，相对**实际图像**的宽高归一化；不是相对外层首屏盒子。设计参考图宽 1440 px，文字 16 px。`宽` 为该尺度的目标组宽；`上限` 为最多可占的图宽比例。摆放图可让图与文字共同缩放；网页不能为塞下文字无限缩小字号。

`row` 为单行；`compact` 为紧凑文字网格；`split` 由两组构成。浅字为 `#FFFFFF`，深字为 `#142C42`。各组透明点击区行高均为44 px；不画网格线、卡片、背景块或说明。原八项索引0–7按既有顺序，`theme`只表示原主题按钮。

这些落点已在提供的截图裁切图上叠字核看，仍是原 SVG 的设计起点；缩略图不能代替原 SVG 的精确色边、动画与手机构图。10、18的薄留白尤其需要原稿确认。

## 必要的单款约束

**02：**以随包主原型为准。桌面中下单行，中心y=0.71，容器730 px，实际内容约720 px，含原主题按钮。手机八项链接为4列×2行，文字14 px，每行44 px；主题按钮在其下方再占44 px，整组高132 px，中心y=0.72。没有菜单或新标签。

**02的衔接：**蒙版段在完整图像之后，桌面128 px、手机96 px；只有原图最后8 px向同纸色羽化。导航不会受到图内长距离渐隐影响。

**10：**顶部两块天空允许各放一个短组，但太阳、月亮离文字很近。只要原 SVG 的日月大小或天空色边与截图不同，就应重新核对每个字的落点。

**18：**中央叠色全部避开，采用顶部两角尚未叠色的暖白窄区。两行文字已接近这两块空白的高度上限；不能把该配置当作任意屏幕比例下都成立的通用坐标。

**15：**使用红日下方、海平面上方的暖色空白，紧凑三行。没有采用顶端单行，以免导航擦过红日上缘。

## 原稿核对

每款只检查四件事：八个栏目与主题按钮都直接可见；同一个词没有跨越明暗色边；人物、日月、桥、建筑和关键路径未被盖住；点击区不重叠。动画开启时也按同一条件检查。02以外的手机位置需依据现有手机版原图确认，不把桌面百分比机械搬到手机。
